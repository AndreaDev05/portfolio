Una selezione dei lavori realizzati durante gli studi

CA-Mobility — Gestione Mobilità Overseas
Web app full-stack · progetto universitario (Tecnologie e Applicazioni Web)

Applicazione web che gestisce l'intero iter della mobilità internazionale (Overseas) di Ca' Foscari: dalla candidatura dello studente al Learning Agreement, fino al riconoscimento degli esami al rientro. Il sistema modella tre ruoli con permessi diversi — studenti, docenti referenti e ufficio Overseas — lungo le tre fasi della mobilità.

  • Front-end SPA in Angular 19
  • API REST in Node.js + Express + TypeScript
  • Database MongoDB con Mongoose
  • Autenticazione JWT e autorizzazione per ruolo
  • Upload documenti e notifiche via Socket.io
  • Ogni componente in un container Docker
Angular TypeScript Express MongoDB JWT Socket.io Docker
