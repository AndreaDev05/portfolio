About

A little about me

I'm 20, and my passion for programming began in high school at ITIS "E. Fermi" in Bassano del Grappa, where I earned a diploma in Computer Science and Telecommunications. I'm now pursuing a Bachelor's degree in Computer Science at Ca' Foscari University of Venice.

During my studies, I've built several real-world projects: from a full-stack web app for managing international student mobility (Angular + Express + MongoDB, containerized with Docker) — later re-engineered with a Python/Flask back end and a relational database while reusing the same front end — to Python networking applications (encrypted chat and real-time video calls) and PHP web apps.

My main areas of interest are data science, AI and machine learning, and IoT, supported by a foundation in software development and networking (Cisco CCNA certified).

CA-Mobility — Overseas Mobility Management
Full-stack web app · university project (Web Technologies and Applications)

A web application that manages Ca' Foscari's entire Overseas international mobility process: from student applications and Learning Agreements to credit recognition after returning. The system supports three roles with different permissions — students, faculty coordinators, and the Overseas office — across all three stages of the mobility process.

  • Angular 19 single-page application
  • REST API with Node.js + Express + TypeScript
  • MongoDB database with Mongoose
  • JWT authentication and role-based authorization
  • Document uploads and notifications via Socket.io
  • Each component runs in a Docker container
Angular TypeScript Express MongoDB JWT Socket.io Docker
